# EduHub - Test Cases

## 1. Create Club
- Input: A valid club name and a member count greater than zero.
- Expected result: The club is created successfully.

## 2. Create Event
- Input: A valid event title and a capacity greater than zero.
- Expected result: The event is created successfully.
- Invalid case: A capacity less than or equal to zero must be rejected.

## 3. Registration
- Input: A member registers for an event.
- Expected result: The registration is created with Pending status.

## 4. Confirm Registration
- Input: A pending registration.
- Expected result: The registration status changes to Confirmed.

## 5. Check-In
- Input: A confirmed registration.
- Expected result: The check-in is recorded successfully.

## 6. Invalid Operation
- Input: An operation that violates a domain rule.
- Expected result: An InvalidOperationException is raised and handled by the console demo.
